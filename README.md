# Countify

Countify delivers real-time word counting with a distraction-free interface and seamless theme switching. The application runs entirely on the client side, ensuring fast performance, zero dependencies, and complete privacy.

This project was built with simplicity, performance, and scalability in mind.

## Features

- Real-time word counting
- Clean and modern UI
- Dark mode toggle
- Responsive design for desktop and mobile
- One-click text clearing

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (icons)
- Google Fonts
